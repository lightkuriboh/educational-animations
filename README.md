# Educational Animations

A collection of interactive, scientifically accurate 3D biomedical and educational web visualizations built for university-level biology, medical students, and science education.

---

## 🔬 Interactive Visualizations

### 1. [External Genitalia Morphogenesis & Anatomical Homology](./genitals-edu/)
- **Description:** Interactive 3D visualization demonstrating morphological differentiation and anatomical homology of human external genitalia during embryonic organogenesis from gestational Week 7 bipotential tissue along the 46,XX and 46,XY (androgen/DHT-mediated) pathways.
- **Technologies:** Three.js (r128), GSAP 3, Vanilla JavaScript, Procedural Morphing Engine, Dark Medical Lab UI.
- **Live Interactive Web App:** [https://lightkuriboh.github.io/genitals-edu/](https://lightkuriboh.github.io/genitals-edu/)

---

## 🛠️ Tech Stack & Philosophy
- **Zero Build Step:** Standalone single-file or lightweight static applications with no node build requirement to run.
- **High Visual Fidelity:** Custom procedural geometries, dual rendering modes (Sculpted Clay & Clinical Atlas), dynamic lighting, and accessible medical dashboard interfaces.
- **Anatomical & Pedagogical Rigor:** Strict adherence to medical terminology and embryological standards (Langman's Medical Embryology, Netter's Atlas).
